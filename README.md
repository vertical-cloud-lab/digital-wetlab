# digital-wetlab

Digital wet lab at the Vertical Cloud Lab @ BYU: self-driving inorganic precipitation experiments
on an Opentrons OT-2, Pitzer-model gaps for sulfide and sulfate scales, and the proposals built on
them (ACS PRF Doctoral New Investigator, TMS 2027).

The proposal work in this repo moved here from the private `vertical-cloud-lab/digital-wetlab-private`
in October 2026.

- **Numbers moved up by 13.** This repo already had items 1–13, so item #N of the private repo is
  #(N+13) here: private #1 is #14 and private #65 is #78.
- **Issues** were transferred here, so old issue links redirect.
- **Open pull requests** were recreated here from the same branches. Their review comments and
  commit-by-commit history stay in the private repo.
- **Closed pull requests** have a closed placeholder issue at their number, so every link still
  lands on the right item.
- **Files that stay private** were left out: CVs and biosketches. ACS documents and figures with
  third-party photos are listed in [`THIRD_PARTY_ASSETS.md`](THIRD_PARTY_ASSETS.md).

Proposals, papers, etc.
